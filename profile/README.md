## Overview

Nexus Mods is one of the largest communities for PC game modifications, providing a centralized place to discover and share user-created content for thousands of games.

Nexus Mods currently lists more than **5,400 supported games**, hundreds of thousands of hosted mods, billions of downloads, and a large international community of players and creators.

The platform is especially well known among players of games such as Skyrim Special Edition, Fallout 4, Skyrim, Cyberpunk 2077, Fallout: New Vegas, Stardew Valley, Baldur's Gate 3, The Witcher 3, Starfield, and many other PC titles.

## Mod Compatibility

Not every mod works with every version of a game.

Major game updates can change files, APIs, scripting systems, or compatibility requirements.

When installing multiple modifications, users should check whether they are designed to work together.

Vortex can help identify certain conflicts, but it does not guarantee that every combination of mods will work correctly.

## Mod Load Order

Some games require modifications to be loaded in a specific order.

Load order can affect which files or gameplay changes take priority when multiple mods modify the same systems.

A properly configured load order can reduce conflicts and improve stability.

The correct load order depends on the game, installed mods, and the requirements specified by individual mod authors.
